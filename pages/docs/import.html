Import, sessions and catalogs.

Rawtonic keeps your photos in a library of one of two kinds: a session for one shoot or assignment, or a catalog for your whole collection. Both use the same editing tools. Import brings photos into the open library; your original files are never changed by it.

{{shot "import-dialog" "the Import dialog with a memory card's photos, one rated in the large view"}}

Session or catalog?

Session
One folder that holds everything of one job: Capture for the photos, Selects for the ones you pick, Output for exports, Trash for what you throw out, and the edits beside them. Move or copy the folder to another disk or computer and it opens there as it was. Use it for a shoot, a client job, a day of work.
Catalog
One catalog for your collection, with albums, smart albums, keywords and search across years of photos. Photos are copied into the catalog folder by default; with Add folder… photos can also stay where they are and only be listed in the catalog (they then do not travel with the catalog folder, which the dialog says).

New session or catalog… (⌘N, Ctrl+N) and Open session or catalog… (⌘O, Ctrl+O) are on the start screen and in the menu. The library’s name in the top bar opens the same choices.

Importing photos

Import in the top bar (⇧⌘I, Ctrl+Shift+I) opens the Import dialog; putting in a memory card opens it too, and you can drop photos or folders on the window. The photos fill the dialog; the settings sit in a column beside them: destination, file naming, metadata.

  • Copy or add. Copy to … copies the photos into the library. Add where they are lists photos from a disk without copying them. Photos on a memory card are always copied, since a card is erased and reused.
  • Every copy is checked. Each copied file is compared with its source by its SHA-256 checksum before it counts as imported. A file of the same name already there is never written over, and photos already in the library (same size and content) are marked In library and skipped.
  • Second copy writes a backup of every photo to another disk in the same import. Eject … after the import ejects the card, but only when every photo came off it copied and verified.
  • Look before you copy. Double-click a photo or press Space for the large view; a click or Z shows 100 % around the pointer, so you can check focus before anything is copied. P includes a photo, X leaves it out, 0–5 rate it; the rating comes into the library with it.
  • File names and metadata. Name the copies from tokens (date, original name, counter, …) and fill creator, copyright ({year} becomes the capture year) and keywords from a Metadata preset. The same naming editor is used for renaming and for export.
  • RAW and JPEG of the same shot come in as one photo, unless you tick Import JPEGs next to RAW files as separate photos.

You can keep editing while an import runs; the Activity centre shows how far it is.

Hot folder

Hot folder in the top bar watches a folder (for example the one another program saves tethered shots to) and copies every new, complete photo into the library as it arrives, checked like an import. Each new photo can get a rating, keywords, a metadata preset and develop settings. For a camera on USB, see Tethering.

XMP sidecars and other programs

Ratings, colour labels and keywords in XMP sidecars are read when photos come in, and Rawtonic writes yours to the photo’s XMP sidecar, so other programs see them (Settings → General, on by default). If another program changed a sidecar since, Rawtonic does not write over it: the top bar shows how many sidecars differ, and you choose Keep library or Use XMP. Your edits themselves stay in the library and in Rawtonic’s own sidecar beside the photo.

Synchronize Folder… brings the library in line with the disk after files were moved, renamed, added or deleted outside Rawtonic: it shows what it found (moves it could verify byte for byte, new photos, missing ones) and changes only what you tick. Files on disk are not changed by it.

Taking a catalog to another computer

Export as Catalog… makes a new catalog of the selected photos, for example to edit a job on a laptop. Import from Catalog… brings the work back: photos are matched by their identity or the content of their original, never by file name; for photos changed on both sides you choose what wins, and the side that loses is kept as a snapshot.

If you come from Lightroom or Capture One: a catalog works like Lightroom’s and Capture One’s, a session like Capture One’s. To bring your existing library over, see From Lightroom or Capture One.
