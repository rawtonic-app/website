Export.

Export turns your edits into files to share, print or hand on: JPEG, TIFF, PNG, WebP, AVIF or JPEG XL, at the size and quality you choose. Your RAW files and your edits are never changed by it.

{{shot "export-dialog" "the Export dialog with two recipes ticked"}}

Recipes: settings you use again

A recipe is a saved set of export settings: format, size, quality, sharpening, metadata, destination, naming. Set up the dialog once and click Save as recipe; next time, tick the recipe instead of setting everything again.

  • Several at once. Tick more than one recipe to export each photo in several versions in one go, for example a full-size TIFF for print and a small JPEG for the web. Rawtonic develops each photo once and writes every version from it, so two recipes take far less than twice the time.
  • No recipe ticked means the dialog’s current settings export.
  • Editing a recipe: click its name; the dialog shows its settings and saves your changes to it.
  • The menu bar’s Export with Recipe exports the selected photos with one recipe without opening the dialog.

With exactly one photo selected, Save As… exports it under a name and into a folder you pick in the system’s save dialog.

If a file exists

Under Destination you choose what happens when a file of the same name is already there: Ask, Keep both (new name), Skip or Replace if changed. With Keep both nothing is ever written over. The choice is saved with each recipe, so a recipe for re-exporting a whole shoot can skip or update what is already done.

A file size limit for JPEG

Competitions, client portals and online forms often accept only files up to a certain size. Turn on Limit file size to … KB under the file settings and Rawtonic finds a high JPEG quality at which the whole file, metadata and colour profile included, stays under the limit (1 KB is 1000 bytes). The quality field then reads “auto”.

Rawtonic never makes the picture smaller to reach the limit: you decide the pixel size under Photo sizing. If even the lowest quality is too big, it writes the smallest file it could make and tells you, in the export queue and in the Activity centre, which files are over their limit, so you can choose a smaller size and export those again. The limit is saved with each recipe.

Super Resolution

Super Resolution (2×, AI) under Photo sizing enlarges each photo to twice its width and height with an AI model before resizing, borders and output sharpening, so a 24-megapixel photo exports at 96 megapixels. Use it for large prints and for heavy crops that would otherwise be too small.

The model enlarges faithfully and invents no texture: halved and enlarged again, our test photos came back as close to the originals as with the enlargement in the leading commercial RAW editor we compared it with. It takes about 6 s for a 24-megapixel photo on a recent Mac’s graphics card at Full quality.

Full
Averages four turned copies of each part of the photo: the cleanest result.
Fast
Enlarges each part once: a quarter of the work, with differences visible only in pixel comparisons. A good choice on computers without a fast graphics card.

The model downloads the first time you tick the option; the dialog says when it is ready. Super Resolution is part of the recipe, so a “print” recipe can always enlarge and a “web” recipe never does.

Photos with generated areas

If an AI tool generated part of a photo (for example when removing an object), the exported file says so in its metadata, as the law in the EU requires. Nothing changes for photos without generated areas.
