Keyboard shortcuts.

Rawtonic’s default keys, in the groups of Settings → Controls. Every key can be changed there, and an action without a key can get one.

This list is made from the app’s own key table each time the website is built for a release, so it shows the keys of the current version and cannot go out of date. Punctuation keys are named as on a US keyboard; on yours, the key in the same place counts, and Rawtonic shows its character in menus and Settings. Some keys do one thing in the Library and another in Develop (E: loupe or eraser, S: stack or crop); they are listed in both groups.

More keys

  • Sliders: a focused slider moves with the arrow keys; double-click resets it; press and hold its name to see its default (see Develop).
  • Import dialog: Space or a double-click for the large view, Z for 100 %, P include, X leave out, 0–5 rate.
  • Esc leaves full screen, a tool or a dialog.
