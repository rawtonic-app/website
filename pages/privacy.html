Privacy.

This website counts no visitors and loads nothing from other sites. The Rawtonic app has no account and no tracking. This page says what is processed anyway, where, for how long, and how to have it deleted.

As of 24 October 2026, for Rawtonic {{release.version}}. The app’s own, more detailed privacy notes: PRIVACY.md.

This website

  • No cookies, no analytics, no third parties. Pages, images and the typeface come from this server only. There are no tracking pixels, embedded videos, maps or social buttons.
  • Server logs. Like any web server, the servers that deliver rawtonic.cc record each request: IP address, date and time, the page or file asked for, the referring page and the browser’s identification. They are used only to keep the site running and secure (Art. 6 (1) (f) GDPR) and are deleted after OFFEN FÜR NUTZER: retention period of the web server logs.
  • Downloads come from GitHub. The download buttons link to the release files on github.com. Clicking one sends your request to GitHub, under GitHub’s privacy statement; so do the other links to GitHub.

The app

Photos, catalogs and edits stay on your computer. Rawtonic goes online on its own for one thing only:

  • Update check. At startup, at most once every 24 hours, Rawtonic asks GitHub’s public releases list whether a newer version exists. On by default; turn off “Check for updates at startup” in Preferences → General. GitHub receives your IP address and the app’s name and version, nothing else: no cookies, identifiers, photos, paths or settings. Rawtonic never downloads or installs an update itself.

Everything else happens only when you ask for it: an AI tool’s model downloads from GitHub the first time you use it, “Show on map” loads a map from openstreetmap.org, links open in your browser. And the contributions below.

Reports and the relay

Problem reports, crash reports and camera test results reach the developers through Rawtonic’s own small service, relay.rawtonic.cc. Nothing is sent unless you click Send after seeing exactly what goes out. You need no account. Legal basis: your consent by sending (Art. 6 (1) (a) GDPR); you can withdraw it by having the report deleted.

What the relay receives

  • Problem report: the text you wrote, and only if you left them in: system details (graphics card), the last 200 lines of Rawtonic’s log, the camera make, model and file type of the open photo, a screenshot of Rawtonic’s window, and, for a photo that renders wrong, the photo’s file if you attach it. Always: Rawtonic’s version, your operating system and its version, the processor type.
  • Crash report: version, system, graphics card, the error message, where in Rawtonic’s code it happened, the names of the functions that were running, and the end of the log of that run.
  • Camera test result: camera model and firmware, system, Rawtonic version, camera driver, each test step’s result and timing. No serial number, file names or photos.

Before you see the text, Rawtonic tries to remove folder paths, your user and computer name, serial numbers, e-mail and IP addresses and GPS positions. That is a help, not a guarantee, so read what you send. A photo file is sent as it is and keeps its metadata, such as the date, the camera’s serial number and a GPS position if one was recorded; the dialog warns you.

Where it goes and for how long

  • The relay runs on Cloudflare Workers. Cloudflare sees your IP address, as any web host does. The relay itself stores no IP address: to limit abuse it counts requests under a keyed hash of the address that changes every hour, day or week and is deleted when that period ends. Request logging is switched off.
  • Each report becomes an issue in a private GitHub repository that only the maintainers can read, filed by the relay’s own account. A screenshot or photo file is kept in private Cloudflare R2 storage, never public.
  • Reports, crash reports and camera tests are deleted after 90 days, with their files. Plain facts from camera tests (which camera works how) may be copied into the public list of tested cameras before that.
  • Processors: Cloudflare, Inc. and GitHub, Inc., both in the United States. OFFEN FÜR NUTZER: basis for the transfer to the US (e.g. EU–US Data Privacy Framework or standard contractual clauses) and the data processing agreements in place

Deleting a report

After sending you see a report id. With it, a report is deleted at once, with its files:

  • in the app: “Delete this report now” in the confirmation after sending;
  • by e-mail: send the report id to hello@rawtonic.cc.

The relay keeps no name or address with a report, so the id is the only way we can find yours.

Other ways to send

Each report dialog can also copy the report (nothing is sent) or open GitHub’s public issue form with the text filled in. That issue is public, filed with your own GitHub account under GitHub’s terms, and only when you submit it there.

Anonymous usage statistics

Off unless you switch on “Send anonymous usage statistics once a week” in Preferences → General (consent, Art. 6 (1) (a) GDPR; switching it off withdraws it and deletes what is kept on your computer). Once a week Rawtonic sends, for the past week: the camera models you opened, which tools from a fixed list you used at all (yes or no), Rawtonic’s version, your operating system and version, the processor type and the maker of your graphics card. No id, no times finer than the week. The relay only adds one to a counter per value and keeps neither the send nor your IP address; the maintainers see a value only when at least ten sends counted it in that week, rarer values are merged into “other”. Counters are kept for two years. As they are only counters, single sends cannot be deleted afterwards. “Show what is sent” in Preferences shows the exact data at any time.

RAW samples

When a camera does not open, Rawtonic can show how to give a sample to raw.pixls.us. Rawtonic sends nothing there: you upload the file on that site yourself, where it becomes public under CC0 and that site’s own terms apply.

Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection, and to withdraw a consent at any time with effect for the future. Write to hello@rawtonic.cc; for a report, include its id. You may also complain to a data protection supervisory authority, for example the one where you live.
