Privacy.

This website uses no cookies, analytics scripts or tracking. Cloudflare, which delivers the site, gives the maintainer aggregate traffic counts; GitHub counts release downloads. The Rawtonic app has no account and no tracking. This page says what is processed, where, for how long, and how to have it deleted.

As of 26 October 2026, for Rawtonic {{release.version}}. The app’s own, more detailed privacy notes: PRIVACY.md.

Mail to this address is forwarded by Cloudflare Email Routing to the maintainer’s mailbox, so Cloudflare processes it on the way.

This website

  • No cookies, no analytics scripts, no tracking. Pages, images and the typeface come from this site only. There are no tracking pixels, embedded videos, maps or social buttons. Cloudflare, which already delivers the site, gives the maintainer aggregated request and visitor counts by day, country and page, without individual profiles. This uses no additional data collection or code in your browser.
  • Delivered through Cloudflare. rawtonic.cc is delivered through Cloudflare, which processes each request (your IP address, the page asked for, the browser’s identification) to deliver the site and protect it from attacks, under Cloudflare’s privacy policy (legitimate interest in a secure, working site; Art. 6 (1) (f) GDPR). The web server behind it keeps no access log.
  • Downloads come from GitHub. The download buttons link to the release files on github.com. GitHub counts downloads of each release file. Clicking one sends your request to GitHub, under GitHub’s privacy statement; so do the other links to GitHub.

The app

Photos, catalogs and edits stay on your computer. Rawtonic goes online on its own for the update check, and, only if you switch them on, for the weekly usage statistics:

  • Update check. At startup, at most once every 24 hours, Rawtonic asks GitHub’s public Releases API (api.github.com, the ten most recent releases of Rawtonic) whether a newer version exists. On by default; turn off “Check for updates at startup” in Preferences → General. GitHub receives your IP address and a User-Agent header of Rawtonic/ and the version, as with any web request; the request carries no cookies, identifiers, photos, paths or settings. Rawtonic never downloads or installs an update itself; a notice links to the release page.

Everything else happens only when you ask for it: an AI tool’s model downloads from GitHub the first time you use it, “Show on map” loads a map from openstreetmap.org, links open in your browser. And the contributions below.

Reports and the relay

Problem reports, crash reports and camera test results reach the developers through Rawtonic’s own small service, relay.rawtonic.cc. Nothing is sent unless you click Send after seeing exactly what goes out. You need no account. Legal basis: your consent by sending (Art. 6 (1) (a) GDPR); you can withdraw it by having the report deleted.

What the relay receives

  • Problem report: the text you wrote, and only if you left them in: system details (graphics card), the last 200 lines of Rawtonic’s log, the camera make, model and file type of the open photo, a screenshot of Rawtonic’s window, and, for a photo that renders wrong, the photo’s file if you attach it. Always: Rawtonic’s version, your operating system and its version, the processor type.
  • Crash report: version, system, graphics card, the error message, where in Rawtonic’s code it happened, the names of the functions that were running, and the end of the log of that run. After a crash Rawtonic keeps this record on your computer and asks once, at the next start, whether to send it; nothing is sent unless you then choose to. “Not now” keeps the record, “Never” deletes all records and stops recording. Records are deleted after sending or after 30 days.
  • Camera test result: camera model and firmware, system, Rawtonic version, camera driver, each test step’s result and timing. No serial number, file names or photos.

Before you see the text, Rawtonic tries to remove folder paths, your user and computer name, serial numbers, e-mail and IP addresses and GPS positions. That is a help, not a guarantee, so read what you send. A photo file is sent as it is and keeps its metadata, such as the date, the camera’s serial number and a GPS position if one was recorded; the dialog warns you.

Where it goes and for how long

  • The relay runs on Cloudflare Workers, with a Cloudflare D1 database. Cloudflare sees your IP address, as any web host does. The relay itself stores no IP address: to limit abuse it counts requests under a keyed hash of the address that changes every hour, day or week and is deleted when that period ends. Request logging is switched off.
  • The D1 database holds, for each report, only a hash of its report id, its kind, the number of its GitHub issue, the names of its stored files and when it arrived; that row is deleted with the report. It also holds the abuse counters above, deleted when their period ends, and the statistics counters (below).
  • Each report becomes an issue in a private GitHub repository that only the maintainers can read, filed by the relay’s own account. A screenshot or photo file is kept in private Cloudflare R2 storage, never public.
  • Reports, crash reports and camera tests are deleted after 90 days, with their files. Plain facts from camera tests (which camera works how) may be copied into the public list of tested cameras before that.
  • Processors: Cloudflare, Inc. and GitHub, Inc., both in the United States. Both state that they are certified under the Swiss–U.S. and the EU–U.S. Data Privacy Framework, which Switzerland and the EU recognise as adequate protection for transfers to certified companies; their data processing terms apply.

Deleting a report

After sending you see a report id. With it, a report is deleted at once, with its files:

  • in the app: “Delete this report now” in the confirmation after sending;
  • by e-mail: send the report id to hello@rawtonic.cc.

The relay asks for no name, account or contact address and keeps none beside a report, so the id is the only way we can find yours. What you write, a screenshot or an attached photo can still contain personal information.

Other ways to send

Each report dialog can also copy the report (nothing is sent) or open GitHub’s public issue form with the text filled in. That issue is public, filed with your own GitHub account under GitHub’s terms, and only when you submit it there.

Anonymous usage statistics

Off unless you switch on “Send anonymous usage statistics once a week” in Preferences → General (consent, Art. 6 (1) (a) GDPR; switching it off withdraws it and deletes what is kept on your computer). Once a week Rawtonic sends, for the past week: the camera models you opened, which tools from a fixed list you used at all (yes or no), Rawtonic’s version, your operating system and version, the processor type and the maker of your graphics card. No id, no times finer than the week. The relay only adds one to a counter per value and keeps neither the send nor your IP address; the maintainers see a value only when at least ten sends counted it in that week, rarer values are merged into “other”. Counters are kept for two years. As they are only counters, single sends cannot be deleted afterwards. “Show what is sent” in Preferences shows the exact data at any time.

RAW samples

When a camera does not open, Rawtonic can show how to give a sample to raw.pixls.us. Rawtonic sends nothing there: you upload the file on that site yourself, where it becomes public under CC0 and that site’s own terms apply.

Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection, and to withdraw a consent at any time with effect for the future. Write to hello@rawtonic.cc; for a report, include its id. You may also complain to a data protection supervisory authority: in Switzerland the Federal Data Protection and Information Commissioner (FDPIC), in the EU the authority where you live.
