Windows blocked the download?

Rawtonic’s Windows downloads are not code-signed yet. Windows and browsers often hold back unsigned programs from a new publisher, although nothing is wrong with them. Before each release, every Windows download is scanned with Microsoft Defender, with freshly updated signatures, on a Windows build machine; the results are in the release’s build log. That is evidence, not a promise that your PC’s protection agrees. So check the file before you allow it.

1. Check the file

Download SHA256SUMS-windows.txt from the release page too. In PowerShell, in your Downloads folder:

Get-FileHash .\{{release.windows.file}}

The SHA-256 it prints must be the one listed for that file in SHA256SUMS-windows.txt (upper or lower case does not matter): {{release.windows.sha256}}. This catches a damaged or swapped download on the way; as the file is not signed, it does not prove who made it.

2. The browser holds it back

  • Edge: open Downloads (Ctrl+J), click … beside the file, then Keep → Show more → Keep anyway.
  • Chrome: in Downloads, choose Keep (or Download dangerous file).

3. Windows Security removed it

Open Windows Security → Virus & threat protection → Protection history. Select the entry for the Rawtonic file, then Actions → Restore (or Allow). Check its SHA-256 as above before you start it.

4. SmartScreen says “Windows protected your PC”

When you start the installer, click More info, then Run anyway.

Still blocked?

Releases after 0.1.0-alpha.11.1 have three Windows downloads of the same app on their release page: an MSI installer (for all users, asks for administrator permission), an installer for your user only (-setup.exe, no administrator rights) and a portable zip that needs no installation. Try another one, and please tell us which file was blocked and by what, so we can report it to Microsoft as a false positive.

Why unsigned? A code-signing certificate costs money every year, and Rawtonic is free. We are preparing free signing for open-source projects; see the code signing policy. Support for the project is welcome on Ko-fi.
