Windows hat den Download blockiert?

Die Windows-Downloads von Rawtonic sind noch nicht codesigniert. Windows und Browser halten nicht signierte Programme eines neuen Herausgebers oft zurück, obwohl mit ihnen alles in Ordnung ist. Vor jeder Version wird jeder Windows-Download auf einem Windows-Build-Rechner mit Microsoft Defender und frisch aktualisierten Signaturen geprüft; die Ergebnisse stehen im Build-Protokoll der Version. Das ist ein Beleg, kein Versprechen, dass der Schutz Ihres PCs zum selben Schluss kommt. Prüfen Sie die Datei deshalb, bevor Sie sie zulassen.

1. Die Datei prüfen

Laden Sie auch SHA256SUMS-windows.txt von der Release-Seite herunter. In der PowerShell, in Ihrem Download-Ordner:

Get-FileHash .\{{release.windows.file}}

Der ausgegebene SHA-256 muss mit dem übereinstimmen, der in SHA256SUMS-windows.txt für diese Datei steht (Groß- und Kleinschreibung spielt keine Rolle): {{release.windows.sha256}}. Das erkennt einen unterwegs beschädigten oder ausgetauschten Download; da die Datei nicht signiert ist, beweist es nicht, wer sie erstellt hat.

2. Der Browser hält ihn zurück

  • Edge: Öffnen Sie die Downloads (Strg+J), klicken Sie neben der Datei auf …, dann Beibehalten → Mehr anzeigen → Trotzdem beibehalten.
  • Chrome: Wählen Sie in den Downloads Behalten (oder Gefährliche Datei herunterladen).

3. Die Windows-Sicherheit hat ihn entfernt

Öffnen Sie Windows-Sicherheit → Viren- & Bedrohungsschutz → Schutzverlauf. Wählen Sie den Eintrag für die Rawtonic-Datei, dann Aktionen → Wiederherstellen (oder Zulassen). Prüfen Sie ihren SHA-256 wie oben, bevor Sie sie starten.

4. SmartScreen meldet „Der Computer wurde durch Windows geschützt“

Wenn Sie den Installer starten, klicken Sie auf Weitere Informationen, dann auf Trotzdem ausführen.

Immer noch blockiert?

Versionen nach 0.1.0-alpha.11.1 haben auf ihrer Release-Seite drei Windows-Downloads derselben App: einen MSI-Installer (für alle Benutzer, fragt nach Administratorrechten), einen Installer nur für Ihren Benutzer (-setup.exe, ohne Administratorrechte) und ein portables Zip, das keine Installation braucht. Versuchen Sie einen anderen, und sagen Sie uns bitte, welche Datei von was blockiert wurde, damit wir sie Microsoft als Fehlalarm melden können.

Warum nicht signiert? Ein Code-Signing-Zertifikat kostet jedes Jahr Geld, und Rawtonic ist kostenlos. Wir bereiten eine kostenlose Signierung für Open-Source-Projekte vor; siehe die Richtlinie zur Code-Signierung. Unterstützung für das Projekt ist auf Ko-fi willkommen.
